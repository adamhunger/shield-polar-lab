# Image inventory

The application draws its live geometry procedurally; these images document the design process and are not runtime dependencies.

| File | Purpose |
| --- | --- |
| `shield_petal.png` | Exact mathematical plot of one petal, with N, A, B, and M labeled. |
| `shield_twelve_petals.png` | All twelve petals in the initial symmetric arrangement. |
| `shield_shifted_petals.png` | Interface reference: N displaced 50°, with M 10° above the equator. |
| `concept-initial-study.png` | Early AI-generated visual study; contains five visible projectors and is not a geometry specification. |
| `concept-six-towers.png` | AI-generated six-tower visual concept. |
| `concept-buttress-arcs.png` | AI-generated flying-buttress light-arc concept. |

The three `shield_*.png` diagrams are generated by the Python scripts in `tools/`. The concept artwork predates the twelve-anchor mathematical model and should not be used to infer dimensions or topology.
